--------------------------------------------------------------------------------
IF A LOGIN STOPS WORKING
--------------------------------------------------------------------------------

  cd server && npm run seed

**does NOT reset an existing password.** It only fills accounts whose password
is empty, so on a database that has been used it reports success and changes
nothing — which is exactly how a login stops working while the seed looks fine.

To actually reset them, set the hash directly (demo accounts only):

  UPDATE users SET password_hash = <bcrypt of chotug123>,
                   failed_login_count = 0, locked_until = NULL
   WHERE status = 'ACTIVE';

Five wrong attempts locks an account for **15 minutes**. The message is
"This account is temporarily locked. Try again later." Clear it with:

  UPDATE users SET failed_login_count = 0, locked_until = NULL
   WHERE lower(email) = 'the@address.here';

Anyone can change their own password from their profile.
